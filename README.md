# 📊 KRX 퀀트 마켓 레이더 (KRX Quant Market Radar)

> **실시간 대한민국 증시 3대 지수 & 10대 핵심 퀀트 스캐너 플랫폼**

---

## ⚡ 주요 기능 (Features)

1. **⚡ KRX 변동성지수(VKOSPI) & 3대 지수 레이더**: 09:00~15:30 실시간 분 단위 정밀 시계열 및 상관관계 차트
2. **🏛️ 국민연금 DART 5% 대량보유 공시 추적기**: 대형 기관 수급 유입/이탈 실시간 모니터링
3. **🛡️ 하락장 역주행주 (Bear-Market Alpha) 스캐너**: 4대 퀀트 필터링 기반 시장 역행 강세주 발굴
4. **🔥 외인·기관 쌍끌이 스마트 수급 TOP 20**: 메이저 주포 동시 순매수 집중 종목 레이더
5. **💎 슈퍼밸류 극초저평가 발굴 레이더**: 고ROE + 초저PER/PBR 1·2·3순위 퀀트 랭킹
6. **🚀 52주 신고가 & 골든크로스 모멘텀**: 20일/60일 정배열 돌파 강세 종목
7. **📅 한·미 증시 일정 달력**: FOMC, 금통위, 주요 빅테크 실적 및 경제지표 캘린더
8. **📈 글로벌 국채금리 & 매크로**: 미국채 10년물, 2년물 스프레드 및 장단기 금리차
9. **🌍 국제정세 & 글로벌 매크로 뉴스**: 환율/금리/원자재/해외증시 실시간 뉴스 분류
10. **🏆 코스피·코스닥 시가총액 랭킹 & 🔗 밸류체인**: 산업 생태계 공급망 연결 지도

---

## 🚀 빠른 시작 (Quick Start)

### 로컬 실행 (Local Development)

```bash
# 전체 의존성 설치
npm run install:all

# 백엔드 실행 (Port 6002)
npm run dev:backend

# 프론트엔드 실행 (Port 5174)
npm run dev:frontend
```

### 프로덕션 빌드 (Production Build)

```bash
npm run build
npm start
```
